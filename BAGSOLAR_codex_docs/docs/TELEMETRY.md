# Telemetry

## Required Fields
- simulation time
- epoch
- body id
- position
- velocity
- acceleration
- kinetic energy
- potential energy
- total energy
- momentum
- eccentricity
- semi-major axis

## Export
Support:
- CSV
- JSON

## Telemetry Principles
Telemetry should be generated by the simulation layer, not the renderer.

The same telemetry system should support:
- live graphs
- saved experiment reports
- validation
- debugging

## Phase 3 preparation

The simulation now exposes the current timestep, selected integrator, total
energy, relative energy drift, total momentum, orbital elements, and the most
recent close-approach/collision report through raylib-free domain APIs. These
values are preparation for Phase 5; CSV/JSON recording and live graphs are not
implemented yet.
